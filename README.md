# EduStart — учебный AI-тренажёр

Наша тренировочная версия проекта для трека «Образование».

## Что уже работает

1. Пользователь выбирает предмет.
2. Получает вопрос.
3. Вводит ответ.
4. Сразу видит результат.

Сейчас вопросы временно хранятся в `app.js`. Позже команда заменит их на настоящий backend и AI.

## Как открыть сайт

Не нужна установка программ.

1. Скачайте репозиторий или откройте файл `index.html`.
2. Откройте `index.html` двойным кликом в браузере.
3. Выберите тему и ответьте на вопрос.

## Структура файлов

- `index.html` — страница сайта;
- `style.css` — внешний вид;
- `app.js` — вопросы и проверка ответов;
- `TEAM_GUIDE.md` — инструкция для команды.

## Важное правило

Каждый участник работает в своей ветке и добавляет изменения через Pull Request. Подробности — в [TEAM_GUIDE.md](TEAM_GUIDE.md).
