# Как работать в команде

Этот файл — короткая инструкция для нашей команды.

## Правило №1

Не меняйте ветку `main` напрямую. Создавайте свою ветку под одну задачу.

## Как начать задачу

1. Откройте **Issues** и выберите свободную задачу.
2. Нажмите **Create a branch** или создайте ветку в терминале.
3. Назовите ветку так: `feat/название-задачи`.
4. Изменяйте только файлы, относящиеся к вашей задаче.
5. Создайте Pull Request и попросите одного участника посмотреть изменения.

## Пример

Задача: сделать кнопку проверки ответа.

Ветка: `feat/check-answer`

Pull Request: «Добавить проверку ответа»

## Если вы работаете через сайт GitHub

1. Откройте файл.
2. Нажмите значок карандаша.
3. Отредактируйте.
4. Внизу выберите **Create a new branch for this commit**.
5. Нажмите **Propose changes**.
6. Нажмите **Create pull request**.

Не храните пароли, API-ключи и токены в файлах проекта.
